# Prompt: Build or extend a website

Act as a senior product designer and frontend engineer. Use the WizardSkill workflow.

First inspect the repository: framework, package manager, routes, components, styles, assets, APIs, tests, and deployment setup. Do not assume the stack.

Then:
1. Summarize the current architecture and identify the exact files relevant to the request.
2. Define the audience, primary user action, page hierarchy, visual direction, and responsive behavior.
3. Use only the most relevant references from the WizardSkill catalog. Extract principles; create original work.
4. Implement the requested outcome in the existing stack and conventions.
5. Preserve unrelated pages, authentication, forms, payments, integrations, and data behavior.
6. Include loading, empty, error, success, focus, hover, and disabled states where applicable.
7. Run the available lint, typecheck, tests, and build scripts.
8. Report changed files, checks and actual results, plus any remaining manual setup.

Do not replace the existing design system or redesign unrelated pages. Do not add fake data, testimonials, integrations, or claims. Do not report deployment unless it was performed and verified.
