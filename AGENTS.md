# Repository agent guidance

- Read the root README and the WizardSkill core skill at `.agents/skills/wizardskill/SKILL.md` before substantial design or frontend work.
- Inspect the existing repository before proposing or changing architecture.
- Preserve established UI, behavior, and integrations unless the task explicitly requests a redesign or replacement.
- Use the resource catalog as inspiration and verify provider terms; never copy proprietary assets or layouts.
- Run relevant checks and report actual results. Never invent test, build, or deployment success.
- Keep secrets and user data out of source control.
