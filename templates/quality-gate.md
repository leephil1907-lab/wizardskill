# WizardSkill quality gate

Use the checks that apply to the task. Mark a check only when it has actually been verified.

## Product and content
- [ ] Audience and primary action are clear.
- [ ] Content is accurate; no invented proof or unsupported claims.
- [ ] Navigation and calls to action lead to real destinations.
- [ ] Forms show real validation and honest submission feedback.

## Visual quality
- [ ] Existing brand and design system are respected.
- [ ] Typography hierarchy and spacing are consistent.
- [ ] Images and icons are relevant and licensed.
- [ ] No placeholder blocks, broken assets, or accidental clipping.
- [ ] Layout works at narrow mobile, common mobile, tablet, and desktop widths.

## Interaction and accessibility
- [ ] Keyboard navigation works.
- [ ] Focus indicators are visible.
- [ ] Controls have labels and accessible names.
- [ ] Color contrast is adequate.
- [ ] Touch targets are practical.
- [ ] Reduced-motion preferences are respected.
- [ ] Loading, empty, error, success, active, and disabled states are covered where relevant.

## Engineering
- [ ] Existing routes and unrelated functionality remain intact.
- [ ] No secrets or private data are committed.
- [ ] No unnecessary dependencies or duplicated systems were introduced.
- [ ] Lint completed (record result).
- [ ] Type check completed (record result).
- [ ] Tests completed (record result).
- [ ] Production build completed (record result).

## Delivery
- [ ] Changed files and major decisions are summarized.
- [ ] Actual checks and results are reported.
- [ ] Unverified items and manual setup are identified.
- [ ] Deployment is only claimed if performed and verified.
