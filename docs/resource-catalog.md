## How to use the catalog

1. Start with the user's actual design problem, not with a favorite tool.
2. Choose no more than a handful of references that directly address the problem.
3. Inspect the reference's information hierarchy, spacing, typography, behavior, and responsive adaptation.
4. Write down transferable principles in original language.
5. Build an original implementation using the target project's existing stack and design system.
6. Verify license, attribution, privacy, accessibility, and commercial-use terms before shipping assets or integrations.

## Responsible use

- Inspiration is not permission to copy.
- Confirm the license for each image, font, icon, template, or code component.
- Do not hotlink third-party assets in production unless the provider explicitly permits it.
- Do not send personal data to a design or messaging provider without an approved privacy and security review.
- Verify vendor pricing and delivery claims directly; do not rely on old promotional comparisons.
