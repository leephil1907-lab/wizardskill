# Prompt: Design and build a conversion-focused landing page

Use WizardSkill. Inspect the existing project before editing and preserve its stack and design system unless a new direction is explicitly requested.

Create an original landing page for:
- Product/service: [name]
- Audience: [audience]
- Primary outcome: [outcome]
- Primary CTA: [action]
- Proof available: [verified proof]
- Required sections: [sections]
- Brand constraints: [constraints]

Deliver:
1. Clear positioning and a specific hero headline.
2. A primary CTA visible without scrolling.
3. Credible proof using only supplied or verifiable evidence.
4. A logical problem → solution → benefits → process → objection handling → CTA flow.
5. Responsive layouts and complete interaction states.
6. Accessible typography, contrast, focus states, and semantic structure.
7. Real, properly licensed visual assets.
8. Verified form or CTA behavior; no fake success states.

Research a few references from the WizardSkill resource catalog, but do not copy their layouts or content. Run the project's checks and report the results.
